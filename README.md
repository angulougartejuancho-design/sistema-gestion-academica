Integrantes: Juan Angulo, Daniel Rojas, Daryelin Valverde y Anyel Barrantes

descripcion del sistema desarrollado: el sistema de gestion academica es una aplicacion de consola desarrollada en java, la cual pemite administrar diferentes tipos de personas dentro de una institucion educativa. el sistema facilita el registro, consulta y visualizacion de estudiantes y docentes, aplicando los principios fundamentales de la programacion orientada a objetos.

ademas incorpora validaciones y manejo de excepciones para garantizar la integridad de los datos integrados por el usuario y asi evitar que la aplicaion finalice de forma inesperada

temas aplicados:

Clases y objetos Encapsulamiento Composición Enumeraciones (enum) Herencia Polimorfismo Clases abstractas Interfaces Método final Métodos estáticos Manejo de errores Excepciones propias de Java Excepción personalizada Sucesión de excepciones mediante throws Git y GitHub para trabajo colaborativo

instrucciones para ejecutar el programa: Clonar el repositorio desde GitHub git clone URL_DEL_REPOSITORIO Abrir el proyecto en Apache NetBeans Compilar el proyecto Ejecutar la clase Main.java Utilizar el menú principal para interactuar con el sistema

Ramas de desarrollo:

feature-juan: Desarrollo de la estructura base del sistema, encapsulamiento, composición y utilidades

feature-daryelin: Implementación de herencia y subclases del sistema

feature-daniel: Implementación de interfaz, polimorfismo y lista de personas

feature-anyel: Implementación de validaciones, excepciones, menú principal e integración del sistema
